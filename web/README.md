# web

واجهة Next.js (App Router) بسيطة تستهلك الـ `backend` عبر REST.

```bash
npm install
cp .env.example .env.local
npm run dev
```

## الصفحات

| المسار | الوصف |
|---|---|
| `/` | تسجيل دخول/إنشاء حساب، عرض الباقات، بدء قضية جديدة |
| `/intake?caseId=...` | محادثة الاستقصاء المتسلسلة ثم رفع المستندات الداعمة ثم زر توليد لائحة الدعوى |
| `/documents/[caseId]?docId=...` | عرض المستند المولَّد قسمًا بقسم + زر تنزيل Word |

لا يوجد منطق أعمال هنا — كل شيء عبر استدعاءات `lib/api.ts` إلى الـ backend. التوكن يُخزَّن في `localStorage` (مقبول للـ MVP فقط).
