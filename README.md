# Smart MRO & Garage ERP

> **ملاحظة:** الاسم التجاري النهائي للمشروع لم يُحسم بعد (رُفضت عدة أسماء بسبب تعارضات فعلية في السوق — راجع سجل المحادثة). هذا الاسم عنوان وصفي مؤقت فقط، مأخوذ من عنوان المواصفات الفنية نفسها. لا تعتمد عليه كعلامة تجارية.

نظام SaaS متعدد المستأجرين (Multi-tenant) لإدارة ورش ومراكز صيانة السيارات وأساطيل النقل، مقدَّم من MarkTech Solutions. يدمج بين العمليات التشغيلية الميدانية، الذكاء الاصطناعي للتشخيص، سوق قطع الغيار المستعملة (التشاليح) المدمج بتسعير مزدوج، التتبع اللوجستي، والمحاسبة المتوافقة مع ZATCA — في منصة واحدة بدل الأنظمة التقليدية المجزّأة.

## حالة المشروع (MVP)

هذا نموذج أولي يغطي **المسار التشغيلي الكامل لأمر شغل واحد من البداية للنهاية**، من أصل 11 وحدة في المواصفات الكاملة:

**منجز فعليًا:**
- بنية قاعدة بيانات متعددة المستأجرين كاملة (تغطي كل الوحدات الـ11 بنيويًا)
- تسجيل ذاتي للورش (Self-service onboarding) + اشتراك تجريبي تلقائي
- صلاحيات أدوار (RBAC): مدير عام، استقبال، فني، محاسب، مشرف مستودع
- إدارة العملاء والمركبات
- أمر الشغل: فتح، تغيير الحالة، صور الأضرار، رموز تحقق OTP للاستلام والتسليم (مع بديل موثّق عند التعذّر)
- بنود أمر الشغل: مصنعيات، قطع جديدة، قطع مستعملة بهامش ربح للورشة
- كتالوج قطع الغيار + سوق التشاليح: موردون، عروض، تقييمات (من 5 نجوم)
- **مساعد تشخيص فعلي بالذكاء الاصطناعي**: يستلم أكواد DTC ويُعيد أسبابًا محتملة وخطوات إصلاح
- **فاتورة ZATCA فعلية**: حساب ضريبة القيمة المضافة (15%) وتوليد رمز QR بترميز TLV حسب المرحلة الأولى المبسّطة
- مؤشر أداء أساسي للفنيين (وقت إغلاق أمر الشغل)
- واجهة ويب: تسجيل ورشة، عملاء/مركبات، أوامر شغل، تشخيص، فاتورة

**غير منجز عمدًا** (يحتاج بيانات اعتماد/أجهزة/عقودًا حقيقية لا يمكن افتراضها) — راجع [`docs/ROADMAP.md`](docs/ROADMAP.md):
- ربط أجهزة فحص OBD-II فعليًا (لاسلكيًا)
- تكامل شركات الشحن الفعلي للتتبع اللحظي (Aramex/SMSA...)
- بوابة رسائل SMS / WhatsApp Business API فعلية
- بوابة دفع فعلية لاشتراكات الورش
- تطبيق جوال مستقل للفنيين والعملاء (الويب الحالي متجاوب لكنه ليس تطبيقًا أصليًا)
- كتالوجات OEM رسمية كاملة (الكتالوج الحالي بنية فارغة تُعبَّأ لاحقًا)

## البدء السريع

```bash
# 1) قاعدة البيانات
psql "$DATABASE_URL" -f database/schema.sql
psql "$DATABASE_URL" -f database/seed_sample_data.sql

# 2) الباك-إند
cd backend
npm install
cp .env.example .env
npm run dev            # :4000

# 3) واجهة الويب
cd ../web
npm install
cp .env.example .env.local
npm run dev            # :3000
```
