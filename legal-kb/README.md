# legal-kb

ملفات تلقين قاعدة المعرفة القانونية.

- **`seed/sample_articles.json`** — بيانات **تجريبية فقط** (نصوص مواد وهمية واضح عليها `[نص تجريبي غير رسمي]`) لاختبار تدفق النظام كاملًا برمجيًا (استرجاع → توليد → تحقق استشهادات → تصدير Word) دون انتظار توفر النصوص الرسمية. **لا تُستخدم كمرجع قانوني بأي حال.**
- **`data/`** *(غير موجود بعد، أنشئه عند توفر النصوص الحقيقية)* — هنا توضع ملفات JSON بنفس بنية `seed/sample_articles.json` لكن بالنصوص الرسمية الكاملة المنقولة حرفيًا من `laws.moj.gov.sa` أو جريدة أم القرى.

## تشغيل التلقين

```bash
cd backend
npm run seed:legal-kb                                    # يحمّل seed/sample_articles.json (التجريبي)
npm run seed:legal-kb -- --file ../legal-kb/data/real.json  # يحمّل ملفًا حقيقيًا لاحقًا
```

راجع [`../docs/LEGAL_KNOWLEDGE_BASE.md`](../docs/LEGAL_KNOWLEDGE_BASE.md) لشرح بنية الجدولين وضمانة منع الاستشهاد المُختلَق.
